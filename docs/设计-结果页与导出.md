## 2. 图表技术选型与规格

选型：**ECharts 5 UMD 本地化**（`frontend/echarts.min.js` 本地内联，零 CDN）。
手写 SVG 需自研 hover/图例/导出，Chart.js 交互弱于 ECharts；两者均弃用。
降级：`typeof echarts === "undefined"` 时图表区渲染数字表格并 `console.warn`，不阻塞主流程。

| 编号 | 图表 | 类型 | 数据源（前端聚合，无新接口） |
|---|---|---|---|
| C1 | 功能点类型分布 | 饼图 | `items[].type` 分组计数 |
| C2 | 重用度分布 | 柱状 | `items[].reuse` 分组计数 |
| C3 | 一级模块工作量占比 | 横向条形（US 降序 Top15 + 其余合并） | `buildResult()` 既有 `sys` 聚合 |
| C4 | 工作量三值区间 | 条形（低/中/高 人天） | `gSummary.work.{low,mid,high}` |

通用要求：hover 显示数值与占比；`buildResult()` 末尾调用 `refreshCharts()`（dispose 旧实例防泄漏）；
每图 `toolbox.saveAsImage` 导出；颜色从 CSS 变量读取（brand/ink/card/grid），随主题切换重建；
容器高 220px × 2 行，监听 resize。

> 主题切换的两个实现要点（T03695 修复）：`_charts` 必须显式挂到 `window` 上，否则刷新守卫恒为假、
> 图表停留旧配色；ECharts 系列标签默认 `#333` + 2px 白描边，深色下会呈「白边包深字」的重影，
> 需按主题把字色设为 `--ink`、描边色设为 `--card`。

## 3. 导出管线

入口：结果页 KPI 区右上角「导出 ▾」下拉（成品 xlsx 为第一项）。

| 项 | 实现 | 验收要点 |
|---|---|---|
| 评估报告 PDF | 纯前端打印管线：`@media print` 隐藏导航/步骤条/按钮，KPI 与四图在前，明细分页表头重复；`window.print()` 由用户另存为 PDF。**不引入 puppeteer**。打印前用 `echarts.getDataURL` 把 canvas 换成 `<img>`，避免打印空白 | 打印预览无导航元素、图表可见 |
| 功能点 CSV | 前端 Blob：`\uFEFF` BOM + 全字段（seq/system/m1/desc/count_item/type/reuse/modify/cx），文件名 `<标题>-功能点明细.csv` | Excel 双击不乱码 |
| Markdown 摘要 | 模板：标题/时间/方法/KPI/四类分布表格/Top10 明细；`navigator.clipboard.writeText` 复制 + 下载 `<标题>-摘要.md` | 粘贴到邮件/文档格式完整 |

全部为同步轻量操作（2000 行明细 ≈ 数百 KB），不阻塞主线程。

## 4. 信息架构（FR-3.2）

1. **分区锚点导航**：页签升级为「页签 + 锚点」双模式 —— sticky 导航条 `结论摘要 | 国标造价 | 明细 | 导出`；
   结论/明细/导出为页内锚点（`scrollIntoView` + 高亮），国标造价点击切页签后定位；
   滚动高亮用 IntersectionObserver（节流 200ms）
2. **分区折叠**：明细区与导出区加折叠按钮（`aria-expanded` + chevron 旋转）；默认「明细折叠」，首屏只留结论
3. **折叠记忆**：`localStorage('wl_fold')` 按分区键存储
4. **与国标造价页签共存**：国标造价仍为页签，锚点条点击即切页签并定位
5. **打印联动**：打印时全部展开，折叠状态不影响 PDF 完整性

## 5. 可访问性（FR-3.5）

- 图标按钮补 `aria-label`，纯装饰 icon 加 `aria-hidden="true"`（约 15 处）
- KPI 容器与国标造价输出区加 `aria-live="polite"`，明细或因子变更时播报
- 全局 `:focus-visible{outline:2px solid var(--brand);outline-offset:2px}`（令牌化，随主题）
- 折叠按钮 `aria-expanded` + `aria-controls`；锚点导航 `role="navigation"` + `aria-current`
- 审计方式：离线环境无法引入 axe，采用**手工审计清单 + CDP 脚本断言**（aria-label 覆盖率、aria-live 存在、
  focus-visible 样式、对比度复用实测值、键盘链路复用既有用例），结果留档 `logs/`

实测对比度（M5）：light 13.57 / dark 11.87 / muted 5.71 / contrast 21:1，均 ≥ 4.5:1。
