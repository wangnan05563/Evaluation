## 1. 前端拆分与构建（FR-5.1）

- **拆分**：`frontend/index.html` 内联 JS/CSS → `frontend/src/css/*.css`（`10_main` / `20_components` / `30_motion_empty`，按名排序拼接）+ `frontend/src/js/*.js`（12 个功能模块，按名排序拼接）
- **构建**：`scripts/build_frontend.py`（零依赖）按序拼接 → 回写单文件 `frontend/index.html`（入库），保持 exe 自包含；**不引入框架/打包器**
- **守门**：构建前后 JS 语法等价（`node --check` 等价）；构建产物等价性由 S4/S5 套件保证
- **收益**：为多语言、主题维护、表格组件化提供文件级工作面

## 2. 复核表格（FR-1.4–1.7）

1. **排序**：表头点击排序（描述/类型/US/seq），`sortState={key,dir}` 仅作用于渲染副本，`items` 原序不动，seq 引用稳定；再次点击切换/取消
2. **筛选**：模块下拉 + 类型多选 + 重用度 + 「仅看未确认」，与搜索框叠加 AND；0 命中显示空态并提供「清除筛选」
3. **批量改**：表头全选可见行；选中后浮现工具条（设重用度/修改类型/复杂度、批量确认、批量删除）；删除需确认，**不重排 seq**（只标记 `seq_deleted`，渲染层过滤），一次写入后单次重绘 + 刷新合计 + 保存表单状态
4. **粘贴导入**：接受 Excel 复制的 TSV/CSV → 首行表头自动识别列映射（可手调）→ 预览 10 行 → 追加（seq 续号、复杂度默认「中」、未确认），上限 2000 条
5. **键盘**：↑↓ 移动焦点行、Enter 切换确认、Space 展开判定依据、Ctrl+F 聚焦搜索；输入控件聚焦时快捷键让位
6. **性能决策**：2000 条上限下全量重绘约数十 ms，**不做虚拟滚动**；超限再议

**依据与驳回**：行展开除 basis 外并列「AI 建议」来源（llm_enabled 时透传 `ai_source`）。用户改动使结果偏离识别建议时记入驳回队列 `{seq, field, from, to, reason?}`（原因：类型误判/重用度高估/复杂度不符/其他，可跳过），随 `hist_items` 入库可追溯。

**空态/加载/错误**：`emptyState(icon,title,desc,actionHtml)`、`loadingBox(text)`、`errorBox(msg,retryFn)` 三组件统一；
**所有错误态必须含下一步动作**（重试或诊断指引）。

## 3. 识别规则外置与沉淀（FR-2.9）

```json
{"schema_ver":1,"updated_at":"...","rules":[
  {"id":"R-ILF-001","name":"数据结构变更→ILF","scope":"desc",
   "patterns":["(增加|新增|修改|保存|更新).{0,14}(字段|表)"],
   "exclude":["页面|界面|详情|展示"],"type":"ILF","modify":null,
   "priority":10,"enabled":true,"source":"builtin"}]}
```

- 匹配语义：按 priority 排序逐条尝试，`patterns` 任一命中且 `exclude` 全不命中即返回该 type；全部未命中回退默认 EI
- **零回归是切换前置条件**：内置规则导出为 seed 后，用 `replay_recognize` 在 45 条样本 + 历史回放集上对拍，结果完全一致才切换
- 文件缺失/损坏回退内置链并告警；识别响应 `meta.rules_version`，历史记录 params 同步记录
- 沉淀链路：驳回队列 → 复核页「沉淀为规则」生成草稿 → 配置中心「识别规则」页维护 → `data/recognition_rules.json`（`/api/rules`）→ 下次识别生效
- 规则更新后首次识别在结果 alerts 中提示版本与时间

## 4. 设计令牌与主题（FR-3.1、4.1–4.5）

| 组 | 令牌 |
|---|---|
| 色板 | `--brand` 系列 + 语义层（success/danger/warning/surface/ink/line） |
| 字阶 / 间距 / 圆角 / 阴影 | `--fs-*`、`--sp-*`（4px 基）、`--r-*`、`--shadow-*` |

- **亮色默认**：`:root`；**深色**：`[data-theme="dark"]`（bg `#0F172A` / card `#1E293B` / ink `#E2E8F0` / brand 提亮 `#60A5FA` / line `#334155`）；**高对比**：`[data-theme="contrast"]` 纯黑白
- 对比度：正文 ≥ 4.5:1（dark `#E2E8F0` on `#1E293B` = 10.9:1），muted 用 `#94A3B8`
- 主题切换：三/四态开关（亮/暗/高对比/跟随系统）→ `localStorage('wl_theme_mode')`；`applyTheme()` 设置 `data-theme`；
  「跟随系统」监听 `matchMedia('(prefers-color-scheme: dark)')` 实时响应；切换即时生效，**ECharts 需重新 setOption 换色**
- 品牌色定制：6 套预设 + 自定义；写 `--brand/--brand-ink/--brand-soft`（HSL 派生）；`localStorage('wl_brand')`；
  **导出表头联动**：`/api/generate` 携带 `brand_color`，generate_xlsx 仅替换母版表头 fill，保持母版其余样式
- 非法色值：前后端同校验 `/^#[0-9a-fA-F]{6}$/`，回退上次合法值并提示
- 打印：`@media print` 强制亮色令牌，避免暗色费墨
- 动效：拖拽高亮、识别骨架、步骤 150ms 过渡；尊重 `@media (prefers-reduced-motion: reduce)`
