# DEMO · 5 分钟演示脚本

> 用途：评审会 / 售前 / 内网试点现场演示。全程本地运行，不依赖外网；演示数据使用仓库固定样例，不碰客户真实文档。

## 演示材料

- 图文介绍：[工作量评估助手-产品介绍.docx](工作量评估助手-产品介绍.docx)
- 界面图版：[assets/product-intro](assets/product-intro/)
- 样例需求：`data/testdocs/t00928_req.docx`（仓库内固定夹具，识别 9 条）
- 演示模式：结果页「演示」入口，6 页分页；Esc 退出

## 启动

```powershell
cd D:\code\otherProjects\Evaluation
scripts\启动服务.bat
```

浏览器打开 `http://127.0.0.1:8020`。也可直接安装 Releases 中的桌面安装包。

## 5 分钟路径

1. **角色引导**：选择「评估师」，点「用样例 5 分钟跑通」。
2. **上传**：拖入 `data/testdocs/t00928_req.docx`，展示章节解析与候选识别。
3. **复核**：逐条调整类型 / 复杂度 / 重用 / 修改类型；打开右侧证据抽屉，展示原文引用与定位；用「确认低风险」演示批量复核。
4. **结果**：展示 UFP、US、费用汇总；导出成品 xlsx；生成 PDF 审计包。
5. **交付演示**：结果页进入「演示模式」，投屏 6 页摘要；讲解脱敏分享与审计留痕。
6. **历史与版本**：打开历史列表，做一次版本 diff，展示新增 / 删除 / 变更高亮。

## 讲解要点

- 本地优先：计算、存储、界面资源全部本地化，需求文档不出本机。
- 母版保真：成品表沿用企业母版公式与样式，Excel 打开即重算。
- 可审计：每个数值可回溯原文、规则、公式与版本；审计包可签收。
- 人在回路：AI 仅建议，不自动确认、不自动出表；默认关闭。
- 可治理：主题 / 双语 / 权限 / 备份回滚按企业环境配置。

## 演示边界

- 默认不启用 LLM，避免现场依赖外部模型服务。
- 不演示 V2.1 未实现能力（组合看板、报价单、插件 API、100 文档批处理），相关规划见 [prd/未实现需求.md](prd/未实现需求.md)。
