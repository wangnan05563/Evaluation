## 2. E11 组合与产能（未实现）

**目标：** PMO 查看项目组合、偏差与资源负载。

- 组合看板：估算 / 实际 / 毛利 / 风险，支持筛选与下钻。
- 项目仪表盘、人员负载热力、甘特/关键路径（可选）。
- 验收口径：100 个项目 ≤5 秒加载；按权限只见授权项目；负载不把估算当实际。
- 当前判定：无组合看板页面与 100 项目数据源，AC-33 `DEFERRED`。

## 3. E12 商务与费率（未实现/部分）

**目标：** 报价与估算同源，支持多客户、多币种、多费率。

- 多费率卡、多币种、税费、折扣。
- 报价单 / 合同附件 / 版本锁定。
- 验收口径：切换费率卡费用重算且明细可追溯；报价锁定后估算变更不自动改价；汇率变更记录来源与日期。
- 当前判定：已有费率版本选择与重算，但缺多费率卡/币种/逐项追溯矩阵，AC-34 `PARTIAL`；报价锁定 AC-35 `DEFERRED`。

## 4. E13 模板、插件与自动化（未实现）

**目标：** 客户/伙伴可扩展，批量任务可规模化。

- 报表模板 / 主题包导入导出、插件 API。
- 自定义字段进入 xlsx/PDF 导出。
- 100 份文档批处理、CI、失败队列、断点续跑、机器可读报告。
- 验收口径：插件只能访问授权 API；自定义字段导出完整；批处理中断后可从失败项续跑。
- 当前判定：无插件 API、无自定义字段、无 100 文档批处理；AC-36/37 在三期口径中为 N/A。

## 5. E14 品牌与主题（尾部）
