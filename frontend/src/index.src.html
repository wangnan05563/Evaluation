IFPUG评估方法论

1. 方法依据

采用 IFPUG 国际标准功能点估算方法（Counting Practices Manual）对需求规模进行量化，再以基准数据换算工作量与费用。

2. 五类功能点

  • ILF - 内部逻辑文件：由系统维护的数据文件
  • EIF - 外部接口文件：被引用但非本系统维护的数据
  • EI - 外部输入：数据进入系统的处理过程
  • EO - 外部输出：向外部输出数据的处理过程
  • EQ - 外部查询：仅检索无业务处理的查询

3. 复杂度与权重

复杂度按「低 / 中 / 高」记录（仅作参考，不参与 UFP）；母版成品表无复杂度列，UFP 按类别默认权重计算：ILF 10、EIF 7、EI 4、EO 5、EQ 4。

预估功能点法仅统计 ILF（35）与 EIF（15），事务类回退估算功能点权重。

4. 调整因子

  • 重用程度：高 1/3、中 2/3、低 1（复用的功能不计全额）
  • 修改类型：新增 1.0、修改 0.8、删除 0.2
  • 规模变更因子：按估算时机取 1.39（早期）/ 1.21（中期）/ 1.10（晚期）/ 1.00（交付后及运维）

5. 估算流程

在「IFPUG 估算」页上传需求说明书（.docx，可拖拽或点击选择，键盘回车亦可），本地引擎解析后生成候选功能点；在「审核功能点」逐条确认类别、复杂度、重用与修改类型，支持搜索、筛选、排序、批量设置与粘贴 Excel 明细；全部确认后点「确认无误 · 生成结果」，在结果页下载成品表。

6. 历史与导出

「历史估算」支持重开继续调整、另存为新记录、删除，勾选两次估算可逐项对比差异；结果页可导出功能点明细 CSV、Markdown 摘要与评估报告 PDF，并可按 INVEST 生成用户故事。

IFPUG算法说明

1. UFP（未调整功能点）

单一功能点 UFP = 类别默认权重（ILF 10 / EIF 7 / EI 4 / EO 5 / EQ 4）；预估功能点法仅 ILF=35、EIF=15，事务类回退估算权重。

2. US（调整后规模）

US = UFP × 重用系数 × 修改系数

3. 调整后规模

调整后规模 = ΣUS × 规模变更调整因子（估算早期 1.39 / 中期 1.21 / 晚期 1.10 / 交付后及运维 1.00）

4. 工作量（人天）

工作量(人天) = 调整后规模 × 生产率(人时/FP) ÷ 8 × 调整因子 0.8

低 / 中 / 高按中值 ±20% 取上下限。

5. 费用（万元）

费用 = 工作量(人天) ÷ 22 × 人月单价(万元)

人月单价默认 2.57 万元/人月，可在项目参数中调整。

6. 上下限

中值 ±20% 作为下限/上限，供谈判区间参考。

NESMA快速估算

1. 适用场景

需求早期、功能点还拆不细时，只需清点 ILF / EIF（估算法再计 EI / EO / EQ），输入即算规模与费用量级。

2. 两种口径

预估法 UFP = 35 × ILF + 15 × EIF

估算法 UFP = 7 × ILF + 5 × EIF + 4 × EI + 5 × EO + 4 × EQ

3. 即时结果

页面即时给出 UFP、规模（UFP × 需求阶段调整因子 1.10）、工作量（PDR × 规模）与费用（工作量 ÷ 174 × 人月费率 + 直接非人力成本），并附 COCOMO II 与 PERT 三点参考。

4. 与国标造价衔接

点「按此结果进国标造价」可把当前 UFP 带入结果页「国标造价」页签，按 GB/T 36964 继续测算。

PERT三点估算

1. 方法依据

PERT（Program Evaluation and Review Technique，计划评审技术）适用于需求不确定、功能点难以精确计数的变更/迭代型场景，依托专家经验直接对工作量做三点估计。

2. 三值定义（单位：人天）

  • 乐观值 O：一切顺利的最短耗时（模板 F 列「最小」）
  • 最可能值 M：正常情况的最可能耗时（模板 E 列「最可能」）
  • 悲观值 P：含风险的最长耗时（模板 G 列「最大」）

3. 预期工期与标准差

预期 = (O + 4M + P) ÷ 6

标准差 σ = (P − O) ÷ 6

4. 三步操作与项目库

需求输入（新建/选择项目、上传 Word/PDF 或粘贴文本，按配置走 AI 拆分或本地分析，勾选候选导入）→ 估算录入（逐项维护阶段与三值，实时显示预期与 σ）→ 结果与生成（汇总预期总人天、最理想人月、调节系数与实际预估人月，并生成成品表）。项目保存在本地 SQLite（data/pert.db），可随时载入继续编辑。

5. 汇总与调节

  • 分阶段（需求/设计/开发/实施/公共及远程/现场维护）汇总预期人天
  • 最理想人月 = 总预期人天 ÷ 20.83
  • 叠加调节系数（客户 0.06 / 质量 0.06 / 变更 0.05 / 进度 0.06）得实际预估人月

6. 输出映射

开发阶段明细写入成品表 R8 起（B/C 列合并，仅写 D 描述与 E/F/G 三值），其余阶段写入对应阶段行；H 列预期由模板公式自动重算。

7. 成品表母版前提

PERT 成品表以随包内置的空白母版为基座生成：tpl/pert-template.xlsx；如需换用其他母版，用环境变量 WE_TPL_PERT 指向自定义母版文件即可。仅源码裁剪版缺少内置母版时，点「生成成品表」才会提示需自备母版。

SETTINGS配置中心与 AI 辅助

1. 大模型识别增强

可接入任意 OpenAI 兼容接口（OpenAI / Claude / 通义 / 火山 / Agnes / 自定义预设），填写 API 地址、模型名与 Key，支持连接测试、获取模型列表、跳转控制台与恢复默认；Key 仅保存在本机 data/config.json。启用后由模型核对/补全候选功能点，连接异常或超时自动回退本地规则。

2. 项目上下文目录

在配置中心 → 项目上下文目录配置一个代码目录，AI 估算时会扫描其技术栈、目录结构、依赖与规模，把「项目级上下文」注入提示词，使工作量评估更贴合实际代码。

仅扫描技术栈、目录结构与依赖等元信息，不读取业务源码；目录不存在或未配置时 AI 自动跳过。

3. 识别规则

规则按优先级从高到低匹配，命中即判定类型；正则支持多条，可配置排除项。修改保存后下次识别生效并记录规则版本。

4. 费率与基准

按年度维护多版本费率（PDR、人月费率、功能点单价、直接非人力成本与数据出处），估算时选用并记录版本。

5. 母版与公式缓存

可上传新成品母版并登记口径说明，上传后应先用新母版生成一次首件、人工核对列位；公式缓存支持后台补算 / 生成时同步重算 / 不重算，超时自动跳过。

6. 应用更新与运维

在「应用更新」配置更新源 JSON 地址后，启动与打开帮助页会自动检测，新版本可一键下载安装并保留本机配置；运维区支持导出诊断包、导出与导入全部数据（导入前自动备份）。

GENERAL通用功能

1. 国标造价

结果页「国标造价」页签按 GB/T 36964-2018 计算：规模 = UFP × GSC × 阶段因子 CF，工作量 AE = PDR × 规模 × 业务领域因子 SWF × 开发语言因子 RDF，费用 = AE ÷ 174 × 人月费率 + 直接非人力成本；可勾选自定义覆盖基准值并标注「人工调整」。

2. 用户故事导出

结果页按 INVEST 模板把已确认功能点生成用户故事（含验收标准与规模），可编辑后导出 Markdown / CSV，或一键推送到 GitHub Issues（仓库与 Token 自配）。

3. 导出与报告

结果页支持导出功能点明细 CSV、Markdown 摘要与评估报告 PDF（打印管线另存）。

4. 外观与语言

提供亮色 / 暗色 / 高对比 / 跟随系统四套主题，中英双语界面，主色可自定义且导出表头同步。

5. 数据与隐私

计算、存储与界面资源全部本地化，需求文档不出本机；大模型 API Key 仅保存在本机配置文件。
